::: warning No router locally
`deployLocal.ts` does **not** deploy `EXNIHILORouter`. Local trading therefore
takes the per-trade approval path rather than the router's one-click path, and
the router pre-approval modal never appears. Deploy one manually and set
`router` in `packages/site/src/contracts/addresses.ts` if you need to exercise
that flow.
:::

The deterministic addresses above hold only for a fresh `hardhat_reset`. Any
extra deployment shifts subsequent nonces.

## Per-market contracts

Creating a market deploys one `EXNIHILOPool`. Its address is emitted in
`MarketCreated` and can be read with `factory.allPools(index)` /
`factory.allPoolsLength()`.

The pool is the only per-market contract. `airToken` and `airUsd` are **not**
deployed tokens — they are supply counters inside the pool. See the
[glossary](/introduction/glossary).

## Keeping this page correct

Contract addresses change on **every** redeploy, and a redeploy is required
whenever the contracts change (nothing is upgradeable). Both `deployFuji.ts`
and `deployLocal.ts` rewrite their JSON files automatically, but this page and
`packages/site/src/contracts/addresses.ts` are updated by hand.

After a redeploy, update all three:

1. `packages/site/src/contracts/addresses.ts` — what the dApp reads
2. `packages/indexer/src/chain.ts` — addresses **and** `START_BLOCK`
3. this page

A mismatch is silent: the dApp reads an abandoned deployment and simply shows an
empty or stale market.
