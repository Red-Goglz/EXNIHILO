# Until now this file did not exist in the repo and Cloudflare was synthesising
# one, which is why the live rules below appeared without ever being committed.
# Taking ownership of it here so the policy is reviewable in git — but see the
# note at the bottom, because Cloudflare can still override it.
#
# ── The policy, and why it is not a mistake ──────────────────────────────────
# The disallowed agents below are *training* crawlers. The search-time retrieval
# bots — OAI-SearchBot (ChatGPT), PerplexityBot, Claude-User — are deliberately
# NOT blocked, so the docs stay quotable by AI search while the corpus stays out
# of model training runs. Content-Signal states the same thing declaratively.
#
# Google-Extended governs Gemini and Vertex grounding only. It has no effect on
# Google Search or on AI Overviews, both of which use Googlebot, so blocking it
# costs no search visibility.
