# packages/site

The EXNIHILO app: React 19, Vite 7, wagmi / viem, Tailwind.

```bash
npm run dev       # http://localhost:5000
npm run build     # type-check, build, prerender, sitemap
npm run lint
```

Chains are declared in `src/lib/chains.ts`, addresses in `src/contracts/addresses.ts`.
Environment variables: [Local Development](../docs/developers/local-dev.md#frontend).
